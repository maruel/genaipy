# Working in genaipy

- Run `make fix`, `make verify`, `make build`, `go vet ./...`, `make test`, and
  `make test-race` before handing off changes.
- Default tests must remain deterministic and offline. Test process ownership,
  HTTP protocols, cancellation, and failures without installing model packages.
- `make smoke` opts into Python dependency installation and real model downloads.
  Run it only when live model validation is requested; report it when unavailable.
- Keep Python runtime scripts and their embedded Go copies consistent by editing
  the source scripts. Never edit files materialized in a runtime cache.
- Dependency versions are owner-managed; do not silently roll them.
